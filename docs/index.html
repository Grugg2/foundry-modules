Install GM Deck

Use the manifest URL in Foundry’s module installer. Enable GM Deck only in a disposable test world while this alpha remains untested in Foundry.

MANIFEST URL

https://grugg2.github.io/foundry-modules/modules/gm-deck/module.json

  1. 1

    In Foundry, open Add-on Modules → Install Module.

  2. 2

    Paste the manifest URL and choose Install.

  3. 3

    Enable GM Deck in a disposable test world. Open it with Shift + G or the d20 token tools.
